# 🔐 SecureVault – Login Authentication System

A modern and responsive **Login Authentication System** developed as part of my OIBSIP Web Development Internship – Task 4.

The project provides user registration, login validation, protected dashboard access, password validation, and logout functionality.

## 🌐 Live Demo

👉 **[View Live Website](https://ishakamalih-blip.github.io/OIBSIP/WebDev-L2-LoginAuth/)**

## ✨ Features

- 🔑 User Registration
- 📧 Username and Email validation
- 🔒 Password validation
- 🛡️ Secure authentication flow
- 🚫 Duplicate user checking
- ⚠️ Invalid login error handling
- 👤 Protected Dashboard
- 🚪 Logout functionality
- 💾 Client-side session/localStorage management
- 📱 Responsive user interface
- 🎨 Modern and clean UI design

## 🛠️ Technologies Used

- HTML5

- JavaScript
- LocalStorage

- GitHub Pages
